## Cobertura y evidencia local

- Inspeccionados raw SQL y ordenamientos (inventario, contadores, sección vista, admin reset/correcciones/duplicados), rutas/cuerpos/queries, campos personalizados, parsers, export CSV, mails y preview SVG, links y fetch del backend.
- SQL usa parámetros o identificadores fijos/DMMF; búsqueda con `' OR 1=1; SELECT pg_sleep(10); --` no amplía resultados y el sort desconocido usa el default. Requests con dos tiendas sintéticas comprueban aislamiento; `{ name: { contains: '' } }` da 400, sin crear clientes.
- Sin sinks `dangerouslySetInnerHTML`, `innerHTML` o `document.write` en la app revisada. React escapa texto; SVG/mail escapan datos. CSV ya prefija fórmulas con apóstrofo. Logos son URL HTTPS renderizada en navegador; no se encontró fetch backend de URL arbitraria de usuario, extracción de uploads a disco ni ejecución de comandos. No se confirmó SQLi, XSS, SSRF, command injection u open redirect en los caminos revisados; esto no prueba ausencia universal.
- PostgreSQL descartable exclusivo: `127.0.0.1:28473/sec_inyeccion_xss_uploads`, usuarios `qa-sec-1@example.com` y `qa-sec-2@example.com`. Requests HTTP reales a backend en loopback para expansión y XLSX normal; `app.inject` para SQL/operadores. Auth de test exclusivamente local, proveedores externos desactivados o simulados.
- Rojo→verde: 3 regresiones iniciales de tamaño/ZIP/merge; 2 de lectura dispersa/límites; 1 de CSV; HTTP ZIP 200→400 y contaminación de prototipo presente→ausente. El merge gigante se intercepta antes de ExcelJS al reproducir para no agotar la máquina compartida. Pruebas adicionales cubren tamaños ZIP falsos, data descriptors, XML/paths inválidos, alias de nombres reconocidos por ExcelJS, rangos de metadatos, fórmulas con resultado guardado, merges normales y padding.
- Validación: TypeScript frontend/backend; 77 pruebas frontend, 35 unitarias backend y 17 integraciones relacionadas, con máximo 2 workers. Sin build ni suite completa local. CI y enlace de PR se registran en la entrega.
