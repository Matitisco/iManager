# Diseño

Reutilizar InventoryImportReview, la hoja y los tokens de escritorio. Mantener la grilla flexible con min-height: 0 y scroll interno independiente de equipos y mapeo. Mostrar selección de hojas únicamente para archivos con varias hojas, en una fila horizontal de chips con scroll. El enlace de encabezado abre un popover con las opciones actuales y campo de fila; Escape y clic externo lo cierran. Conservar diagnósticos, rojo de columnas sin asignar y recalculado de encabezados.
