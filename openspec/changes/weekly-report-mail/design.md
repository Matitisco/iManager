# Diseño
Reusar resumen periódico y ganancia neta; sumar canjes confirmados, stock y deuda al preparar el envío. Congelar HTML/texto por tienda+período+destinatario. Reclamar cada entrega con transición atómica antes de SMTP; errores ambiguos no se reenvían automáticamente. Message-ID estable y Resend-Idempotency-Key. Worker de una ejecución cada cinco minutos, preparado y desactivado hasta configuración manual. UI propia en Resumen periódico, con dock móvil y acceso desde Configuración. Prueba solo OWNER con límite persistente por tienda. QA exclusivamente en Postgres local y transporte stub.
