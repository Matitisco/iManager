# Dashboard aprobado v2

## Why
Dashboard debe reflejar las referencias aprobadas de escritorio/celular y usar los cálculos financieros de Reports, evitando una comparación local divergente.

## What Changes
- Cuatro KPI, tendencia, medios de pago, ventas recientes y accesos a canjes/saldos con fuentes actuales.
- Rango con aplicación explícita desde calendario flotante desktop y selector móvil; isla existente encima del calendario.
- Comparaciones sin bases despreciables y sin ventas anuladas; agrupación por calendario argentino.

## Non-goals
No modificar Prisma, AppContext, Figma, navegación global ni datos de producción. Sin build ni push.

## Capabilities
Dashboard v2 y corrección acotada de Reports.
