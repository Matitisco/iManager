# Detalle de venta compacto (#286)

El detalle de ventas con canje requiere demasiado scroll para acceder a las acciones. Agrupar los datos del canje y mantener las acciones visibles en desktop e iPhone, conservando textos, permisos y comportamiento. Solo frontend.

Seguimiento QA: garantizar el mismo detalle en todas las aperturas, incluido Reportes; filas de acciones de igual ancho y última acción impar a ancho completo. Verificar ventas largas a 1280×640, 1280×800, 1440×900 e iPhone 13.
