# Eliminar ventas canceladas

La acción Eliminar vuelve a cancelar las ventas integradas y deja el registro visible. La selección masiva también impide procesar las canceladas.

Permitir borrar ventas canceladas sin repetir efectos sobre stock, canje, cliente o pagos. Conservar el comportamiento de ventas activas, permisos por tienda y auditoría. Sin cambios de Prisma.
