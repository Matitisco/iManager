# Diseño

Validación pura compartida para reglas independientes de DB. Reparar mapeos de calidad solo al analizar automáticamente y sugerir definición de texto creada en confirmación. Diagnósticos acotados a 50 rechazos; advertencias de batería sin valores de celdas. Definiciones de tienda y restricciones de DB se validan únicamente al confirmar.
