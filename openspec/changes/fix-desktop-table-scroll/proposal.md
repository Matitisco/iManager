# Scroll horizontal en tablas de escritorio

Ventas y Clientes recortan columnas dentro de tarjetas sin scroll. Inventario y Canjes pierden el scroll bajo 760 px aunque se renderice la presentación de escritorio. Unificar el contenedor desplazable de estas cuatro tablas sin cambiar las tarjetas móviles ni el ancho normal de escritorio. Devoluciones usa una lista, no una tabla.
