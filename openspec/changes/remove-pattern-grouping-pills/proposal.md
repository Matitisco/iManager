# Quitar las pastillas de Patrones

## Why
El selector Proveedor / Compra / Modelo agrega navegación interna innecesaria. El pedido es quitarlo sin perder información.

## What Changes
Mostrar las tres agrupaciones como secciones apiladas con sus títulos existentes. Conservar permisos, detalles, enlaces, estados vacíos y caché. Las otras pantallas se revisan sin modificarlas.
