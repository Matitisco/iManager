## ADDED Requirements

### Requirement: Acción Nuevo campo distinguible
El importador SHALL mostrar «Nuevo campo…» con Plus antes del texto, acento del sistema con contraste legible y separador fino superior.

#### Scenario: Selección accesible
- **WHEN** se abre el destino de una columna en escritorio o móvil
- **THEN** la acción se distingue visualmente y conserva nombre accesible, búsqueda por texto, navegación y selección por teclado existentes.
