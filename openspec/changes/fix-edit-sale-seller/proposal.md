## Why
Las ventas canceladas ofrecen Editar aunque la API las rechaza; el error queda fuera de vista al guardar.

## What Changes
Ocultar Editar en ventas canceladas, proteger el formulario abierto y desplazar los errores de guardado a la vista. Verificar vendedor, auditoría y comisiones sin cambiar importes.

## Impact
Formularios y detalles de ventas, menú contextual y validación de señas. Sin cambios de schema ni estilos.
