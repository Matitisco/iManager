# Design

Reuse ListSkeleton for lists and introduce a small shared Skeleton primitive for inline values and forms. Match the existing DM Sans surfaces and content shapes. Keep accessible loading names and busy states without visible loading copy. Catalog placeholders mirror counters and equipment/summary columns; stock and history retain their layouts. Reference captures and the generated mockup live outside the repository in `/workspace/imanager-local/shots/483-d/`.

Validate with a TypeScript AST source guard, component tests, frontend/backend typechecking and local desktop/iPhone screenshots. No backend or Prisma changes.
